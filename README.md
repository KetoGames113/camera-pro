# كاميرا برو
تطبيق كاميرا ويب (HTML واحد). الجودات: عالية / ضعيفة / ضعيفة جدا، فلترات، مؤقت، تصوير متتالي، فيديو، تكبير، شبكة، ومعرض.

## النشر على GitHub Pages
1. أنشئ مستودع جديد على GitHub.
2. ارفع الملف `index.html` (و `README.md`) للمستودع.
3. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.
4. افتح الرابط `https://USERNAME.github.io/REPO/` من الجوال (يلزم HTTPS للكاميرا).
